# 🛍️ Comfy Store

Comfy Store is a modern e-commerce web application built with React and Vite. It features a clean UI, fast performance, and scalable architecture using Redux Toolkit.

---

## 🚀 Features

- 🛒 Product listing and shopping experience
- 👤 User authentication (demo user/login/register)
- 🔍 Product filtering and search functionality
- ⚡ Global state management with Redux Toolkit
- 🔔 Toast notifications for better UX feedback
- 🎨 Modern UI using Tailwind CSS + DaisyUI
- 📱 Fully responsive design
- 🌐 API handling using Axios
  
---

## 🧰 Tech Stack

- **Frontend:** React 19, Vite
- **State Management:** Redux Toolkit, React-Redux
- **Routing:** React Router
- **Styling:** Tailwind CSS, DaisyUI
- **Icons:** React Icons
- **HTTP Client:** Axios
- **Utilities:** Day.js, React Toastify
